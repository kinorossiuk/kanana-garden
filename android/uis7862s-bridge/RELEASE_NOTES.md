# Kanana Garden v0.2.3

UIS7862S 헤드유닛에서 볼륨·내비게이션·미디어 제어를 직접 확인하기 위한 테스트 릴리스입니다.

## 이번 변경

- FYT 사운드 서비스가 준비되지 않았거나 명령 전송에 실패하면 오류를 표시합니다.
- Android 버전 호환성과 화면 종료 중 비동기 작업 처리를 보완했습니다.
- 차량 명령 평가에서 기대 action과 볼륨·목적지 등 선언된 slot을 함께 확인합니다.
- 진단 기록의 인증 문자열 마스킹과 보고서 수집 안내를 보완했습니다.

## 설치와 시험

`kanana-garden-bridge-0.2.3-release.apk`를 내려받아 설치합니다. 기존 v0.2.0 이상의 정식 릴리스와 같은 서명키를 사용하며, 앱 안에서도 업데이트를 확인할 수 있습니다.

정차 상태에서 앱의 안내에 따라 볼륨 올리기·30% 설정, 서울역 목적지 전달, 음악 재생·일시정지·다음 곡을 확인하고 PASS 또는 FAIL을 선택해 주세요. 결과는 앱에서 LTE 제출하거나 다른 앱으로 공유할 수 있습니다. 미디어 제어에는 알림 접근 허용이 필요합니다.

## 확인된 한계

- 이번 버전의 실제 헤드유닛 동작과 LTE 제출은 아직 확인하지 않았습니다. 볼륨은 API 호출 표시와 실제 음량 변화를 각각 확인해 주세요.
- 모델의 잘못된 action 필드 타입 처리, 일부 비표준 JSON 거부, 낮은 confidence의 추가 확인은 후속 수정이 필요합니다. 고정 버튼은 수동으로 불러온 뒤 실행합니다.
- release APK는 debuggable이 아니므로 USB `run-as` 보고서 수집을 사용할 수 없습니다. 앱의 공유 또는 LTE 제출을 이용하세요.
- 길안내 종료와 검색어 음악 재생은 지원하지 않습니다. LLM과 음성 인식은 APK에 포함되지 않습니다.
