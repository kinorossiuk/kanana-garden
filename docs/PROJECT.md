# Kanana Garden 프로젝트 브리프

## 우리가 푸는 문제

카나나 모델이 공개되어도 첫 실행, 활용 사례 발견, 결과 재현, 기여 방법이
각기 다른 문서와 개인 코드에 흩어지면 생태계의 복리 효과가 생기지 않는다.
Garden은 카나나로 해결한 작은 문제를 표준화된 레시피로 축적하고 누구나 같은
입력 경로로 재실행하게 만든다.

## 핵심 사용자

첫 90일의 핵심 사용자는 한국어 AI 기능을 시험하려는 Python 개발자와
프로덕트 빌더다. 모델 연구자용 학습·평가 프레임워크와 일반 소비자용 완성
서비스는 초기 범위가 아니다.

## 제품 원칙

1. 첫 가치까지 10분: 모델 서버가 있다면 설치부터 첫 결과까지 10분 이내다.
2. 재사용이 우선: 데모 화면보다 복사·검증 가능한 레시피가 핵심 자산이다.
3. 카나나가 기본값: 호환 API를 쓰더라도 레시피와 문서는 카나나 특성을
   기준으로 검증한다.
4. 작은 기여 사다리: JSON 한 파일 → 예제 평가 → 도구 연동 → 완성 앱으로
   기여 난도를 점진적으로 높인다.
5. 측정 가능한 주장: “좋다” 대신 성공 조건이 있는 대표 입력을 쌓는다.

## 북극성 지표와 선행 지표

북극성 지표는 월간 **외부 검증 레시피 실행 수**다. 단순 다운로드보다 실제로
카나나 활용 지식이 재사용된 횟수를 본다.

초기에는 원격 수집을 넣지 않고 다음 공개 지표로 제품-커뮤니티 적합성을
확인한다.

| 지표 | 30일 목표 | 90일 목표 |
|---|---:|---:|
| 실제 모델로 확인된 레시피 | 5 | 20 |
| 외부 기여자 | 2 | 10 |
| 재현 가능한 예제 케이스 | 15 | 100 |
| 첫 결과까지 걸리는 중앙값 | 10분 이하 | 5분 이하 |
| 공개 파생 앱 | 1 | 5 |

## 90일 실행 계획

### 0–30일: 씨앗

- 레시피 스키마, 검증 CLI, OpenAI 호환 실행기를 안정화한다.
- 서로 다른 사용자 문제를 푸는 레시피 5개를 실제 카나나로 확인한다.
- `check`의 `expected_contains` 스모크 결과를 첫 5개 레시피에서 수집한다.
- Raspberry Pi 5 8GB에서 공식 1.3B 모델의 정확성·성능 기준선을 측정한다.
- `pi5-baseline`으로 재부팅 전후 9개 반복 sample과 열·스로틀 증빙을 남긴다.
- `pi5-compare`로 같은 장치의 서로 다른 boot에서 재현됐는지 확인한다.
- GGUF 출력 동등성 확인 전에는 공식 Transformers 경로를 기준으로 삼는다.
- 32개 합성 한국어 패리티 스위트의 공식 런타임 기준 점수를 확정한다.
- 첫 결과까지 걸리는 시간을 5명의 신규 사용자에게 측정한다.

통과 조건: 처음 보는 개발자 4/5명이 도움 없이 내장 레시피 하나를 실행한다.

### 31–60일: 가지

- 도구 호출 레시피 계약과 안전한 로컬 도구 샌드박스를 설계한다.
- 한국어 문서, 소상공인, 접근성 중 실제 파트너 문제 하나를 선택한다.
- 레시피별 모델·프롬프트 회귀 결과를 CI에서 비교한다.
- 예제 결과와 한계를 보여주는 정적 카탈로그를 만든다.

통과 조건: 저장소 관리자 외 기여자가 만든 레시피 5개가 병합되고, 그중
2개가 반복 사용자에게 재사용된다.

### 61–90일: 정원

- 검증된 레시피를 독립 앱으로 내보내는 템플릿을 제공한다.
- 파트너 문제에서 전후 작업 시간 또는 품질 개선을 측정한다.
- 유지보수자 역할, 릴리스 주기, 레시피 폐기 정책을 문서화한다.
- 카나나 새 모델에 대한 호환성 매트릭스를 운영한다.

통과 조건: 외부 팀이 운영하는 파생 앱 2개와 외부 유지보수자 2명을 확보한다.

## 지금 의도적으로 하지 않는 것

- 카나나 가중치 재배포 또는 유료 추론 API 운영
- 범용 에이전트 프레임워크
- 별도 벡터 DB나 관측 플랫폼
- 레시피 수만 늘리기 위한 미검증 프롬프트 수집
- 카카오 공식 프로젝트처럼 보이는 브랜딩

## 첫 검증 인터뷰

아래 질문으로 개발자 5명을 관찰한다.

1. 최근 한국어 LLM 기능을 만들며 가장 오래 걸린 단계는 무엇이었나?
2. 모델 카드를 보고 카나나를 처음 실행하는 데 어디서 막히는가?
3. 기존 레시피를 신뢰하려면 어떤 증거가 필요한가?
4. 결과가 유용했다면 무엇을 다시 커뮤니티에 돌려줄 수 있는가?
5. Garden을 다시 쓰지 않을 가장 큰 이유는 무엇인가?

답을 설명으로만 받지 말고 설치와 첫 실행 화면을 관찰해 시간과 실패 지점을
기록한다.
