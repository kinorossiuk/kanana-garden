# 카나나 모델 라이선스 적용 메모

이 문서는 프로젝트 운영자가 놓치기 쉬운 경계를 기록한 메모이며 법률 자문이
아닙니다. 실제 사용 전에는 대상 모델 저장소의 라이선스 원문을 확인해야
합니다.

2026년 8월 14일 확인한
[`kanana-2-1.3b-instruct` 라이선스](https://huggingface.co/kakaocorp/kanana-2-1.3b-instruct/blob/main/LICENSE)의
핵심 적용점은 다음과 같습니다.

- 모델 가중치는 Kanana License Agreement를 따른다. 저장소 루트의 코드
  라이선스가 모델에 적용되지 않는다.
- 카나나 관련 웹사이트, UI, 글, 소개 페이지, 제품 문서에는
  `Powered by Kanana`를 쉽게 알아볼 수 있게 표시해야 한다.
- 카나나 또는 파생 모델을 재배포하면 라이선스 사본, 수정 표시, 지정 NOTICE,
  후속 사용 제한 고지 등 추가 의무가 생긴다.
- 카나나 또는 파생 모델 접근을 제3자에게 API·클라우드·SI·온디바이스 형태로
  제공하거나 재판매하는 일부 활동에는 카카오가 별도로 부여한 상업 라이선스가
  필요하다.
- 위 별도 상업 조건에 해당하지 않는 자체 서비스의 개발과 운영은 원문 4.3에
  별도로 설명되어 있다.
- 출력의 권리를 카카오가 주장하지 않는다고 되어 있지만, 출력과 그 사용에
  대한 책임은 사용자에게 있다.

Garden은 모델 가중치, 모델 코드, 파생 모델을 배포하지 않습니다. 로컬 또는
사용자가 지정한 OpenAI 호환 서버에 요청을 보내는 클라이언트와 독립적인 JSON
레시피만 배포합니다.

배포 전 체크리스트:

- [ ] 실제 사용하는 정확한 모델 버전의 라이선스를 다시 읽었다.
- [ ] 사용자에게 `Powered by Kanana`가 명확히 보인다.
- [ ] 금지 사용 정책과 책임 있는 AI 가이드라인을 확인했다.
- [ ] 제3자에게 모델 접근을 판매하거나 재판매하는 구조인지 검토했다.
- [ ] 가중치나 파생 모델을 배포한다면 재배포 의무를 모두 이행했다.
- [ ] 카카오의 공식 프로젝트 또는 보증을 암시하지 않는다.
